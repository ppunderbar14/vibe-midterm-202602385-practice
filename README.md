# vibe-midterm-202602385-practice
중간고사 연습용 메뉴·의사결정 룰렛

## 현재 진행 상태

**후보 편집·가중치 원판·회전 결과 구현 완료, 저장 기능 구현 전**

후보를 추가·삭제하고 이름·가중치·색상을 편집할 수 있다. 입력 검증 후 가중치 비율에 맞춘 원판과 선택 확률을 표시하며, 회전이 감속해 멈춘 뒤 화살표 아래 조각 이름을 결과로 보여준다. 프리셋과 저장 기능은 아직 구현하지 않았다.

## 앱 소개

메뉴나 선택지를 등록하고 룰렛을 돌려 하나를 고르는 정적 웹앱이다. 후보별 가중치에 따라 선택 확률과 원판 조각 크기를 다르게 설정할 예정이다. HTML, CSS, JavaScript와 Canvas 2D만 사용하며 외부 라이브러리나 빌드 도구는 사용하지 않는다.

## 구현된 화면

- 앱 이름과 사용 안내
- Canvas 원판과 상단 고정 화살표, 회전·감속 애니메이션
- 한식·중식·일식·양식 샘플 후보, 이름·가중치·색상 입력, 후보 추가·삭제 버튼
- 프리셋 이름 입력과 저장·불러오기·삭제 영역
- 넓은 화면 두 열과 좁은 화면 한 열 배치, 44px 이상 입력·버튼
- 지정된 footer

- 후보 추가·삭제, 이름·가중치·색상 편집과 오류 안내
- 가중치 합을 기준으로 한 후보별 선택 확률 표시
- 후보 색상과 가중치에 맞춘 Canvas 정지 상태 원판
- requestAnimationFrame 경과 시간으로 계산하는 감속 회전
- 회전 중 후보 조작 잠금과 연속 클릭 중복 실행 방지
- 종료 각도가 가리키는 조각에서 결과를 판정해 표시
- 이름을 원판에 읽기 쉽게 표시하고, 공간이 부족한 작은 조각은 후보 목록에서 확인
- 후보는 최대 20개이며 입력 규칙은 이름 1~30자, 가중치 1~100 정수, 색상 `#RRGGBB`
- 프리셋 컨트롤은 아직 비활성 상태
- 후보 상태는 이번 단계에서는 메모리에만 있으며 새로고침하면 기본 후보로 초기화됨

## 아직 구현하지 않은 기능

- 프리셋 저장·불러오기·삭제 동작
- localStorage 저장·복원과 저장 데이터 오류 처리

회전·결과 기능은 요청 범위대로 구현했다. 수정 후 Chrome 자동화 연결이 불안정해 최종 수정본의 실제 브라우저 결과 일치와 360px 화면은 다시 확인하지 못했으며, 작업 기록에 이 제한을 남겼다.

## 실행 방법

`index.html`을 브라우저에서 열면 화면을 볼 수 있다. 설치와 빌드는 필요 없다. `style.css`와 `script.js`는 HTML에서 상대 경로로 불러온다.

저장 기능은 브라우저 설정과 실행 주소의 영향을 받을 수 있다. 직접 파일을 열었을 때의 저장 동작과 GitHub Pages 주소에서의 저장·복원 동작을 각각 확인할 예정이다. 주소나 브라우저가 바뀌면 저장된 목록이 자동으로 옮겨지지 않는다.
