## 앱 소개

메뉴나 선택지를 등록하고 룰렛을 돌려 하나를 고르는 정적 웹앱이다. 후보별 가중치에 따라 선택 확률과 원판 조각 크기를 다르게 설정할 예정이다. HTML, CSS, JavaScript와 Canvas 2D만 사용하며 외부 라이브러리나 빌드 도구는 사용하지 않는다.

## 예정 기능

- 후보 추가·삭제, 이름·가중치·색상 편집과 확률 표시
- 가중치가 반영된 Canvas 원판과 회전·감속 애니메이션
- 화살표와 일치하는 결과 표시, 회전 중 중복 실행 방지
- 프리셋 저장·불러오기·삭제
- localStorage를 이용한 후보·프리셋 유지와 저장 오류 처리
- 모바일 화면 및 키보드 조작 지원
- footer: `법행정세무학과 | 202602385 | 서승환`

## 실행 방법

현재는 문서만 있어 실행할 앱이 없다. 구현 후 `index.html`, `style.css`, `script.js`를 같은 폴더에 두고 브라우저에서 `index.html`을 열어 실행한다. 설치와 빌드는 필요 없다.

저장 기능은 브라우저 설정과 실행 주소의 영향을 받을 수 있다. 직접 파일을 열었을 때의 저장 동작과 GitHub Pages 주소에서의 저장·복원 동작을 각각 확인할 예정이다. 주소나 브라우저가 바뀌면 저장된 목록이 자동으로 옮겨지지 않는다.
